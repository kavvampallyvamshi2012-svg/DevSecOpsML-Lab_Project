DEVSEC MLOPS • LAB EXPERIMENT

ML Model Security Scanning and Remediation

A lightweight static-analysis demonstration for common security risks in Python ML utilities.

Python Experiment

Objective

Identify selected insecure coding patterns and provide remediation advice without executing scanned code.

Workflow

  1. Scan synthetic Python snippets or Python files in a supplied directory.
  2. Check for unsafe pickle deserialization, shell=True subprocess calls, MD5 usage, and hard-coded secrets.
  3. Report rule identifier, severity, file, line, and remediation recommendation.
  4. Optionally invoke Bandit on a supplied project when installed.
  5. Write findings and severity counts to a JSON report.

Configuration

Dataset: N/A — synthetic vulnerable and secure code samples.

Parameters: Rule-based checks: B301, B602, B324, B105 | Optional Bandit recursive scan

How to Run

Run the Python script from the repository root using the commands in README.md. A JSON results report is generated.

Limitations

Pattern matching may produce false positives and miss vulnerabilities. Use Bandit, dependency scanners, secret scanning, and code review for real deployments. Vulnerable snippets are never executed.
