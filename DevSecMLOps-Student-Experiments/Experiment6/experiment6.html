Secure Email Threat Detection Using DevSecMLOps

An educational spam classification pipeline with reproducible preprocessing and evaluation.

Python Experiment

Objective

Classify email messages as spam or ham using TF-IDF features and Logistic Regression, then report standard classification metrics.

Workflow

  1. Load a labeled email CSV or use the included synthetic demonstration samples.
  2. Convert text to TF-IDF features using unigrams and bigrams.
  3. Train a class-weighted Logistic Regression classifier.
  4. Use a stratified holdout when sufficient examples are available; otherwise label results as training-set demo metrics.
  5. Save accuracy, precision, recall, F1-score, parameters, and evaluation notes to JSON.

Configuration

Dataset: SpamAssassin Public Corpus when supplied as a prepared CSV; otherwise built-in synthetic demo samples.

Parameters: TF-IDF (ngram_range=(1,2), max_features=5000) | Logistic Regression (max_iter=1000, class_weight=balanced, random_state=42)

How to Run

Run the Python script from the repository root using the commands in README.md. A JSON results report is generated.

Limitations

The built-in sample is small and synthetic. Do not present its metrics as real-world performance. Avoid logging sensitive email content.
